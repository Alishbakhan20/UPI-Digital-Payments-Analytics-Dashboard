# UPI Digital Payments Analytics Dashboard

## Project Overview
An interactive Tableau dashboard designed to analyze UPI digital payment transactions and identify useful insights.

## Project Objectives
- Analyze transaction trends.
- Compare successful and failed transactions.
- Identify the top 5 banks.
- Understand transaction performance.
- Present insights through interactive visualizations.

## Tools and Technologies
- Tableau
- Microsoft Excel
- GitHub

## Dashboard Features
- Transaction analysis
- Success and failure percentage
- Top 5 bank analysis
- Interactive charts and visualizations
